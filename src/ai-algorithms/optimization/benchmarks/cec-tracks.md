# CEC 赛道与算法演进

赛道划分决定了算法比较所针对的问题与评价协议，研究算法演进时需要先确认这些条件是否一致。

## 按问题属性查找

| 归档维度 | 区别 | 阅读时关注 |
| --- | --- | --- |
| 单目标 / 多目标 | 优化一个指标，或寻找多个指标间的折中解 | 误差或解集评价指标 |
| 边界约束 / 一般约束 | 变量取值范围，或额外的等式与不等式约束 | 可行性规则、约束违反量与可行解评价 |
| 迁移与多任务 | 跨问题或任务利用已有信息 | 可用知识、迁移方式与额外计算成本 |

这些维度可能组合，并不是每年都举办相同赛道。例如 [2024 年资料库](https://github.com/P-N-Suganthan/2024-CEC)包含不同目标与约束类型的资料，[2021 年迁移多目标报告](https://arxiv.org/abs/2110.08033)则对应具体的迁移优化基准。

大规模、昂贵、多峰或动态等[研究方向](../frontier-algorithms/research-directions.md)也可作为检索标签，但某年是否举办对应竞赛，需要当年的原始资料确认。

## 冠军算法发展线如何记录

按一个具体赛道建立时间线，每个年份保留官方名次依据，再把算法链接到独立的论文笔记。建议使用下面的字段：

| 字段 | 用途 |
| --- | --- |
| 年份、赛道与协议 | 确认比较对象和规则版本 |
| 获奖算法与准确名次 | 区分冠军、亚军、并列名次和其他奖项 |
| 原始结果来源 | 标记文件、表格或页码，便于回查 |
| 关键机制 | 参数适应、种群调整、混合搜索、代理模型等 |
| 相较前代的变化 | 根据论文辨明继承关系与改动 |
| 证据与限制 | 区分消融支持、排名变化和个人推测 |

目前先建立索引方式，尚未形成经逐年核对的冠军时间线。后续结合[年度资料](./cec-resources.md)补齐，再分析机制的延续与变化。

## 趋势分析的边界

不同年份的问题、维度、预算和评分方式可能变化，不能只按名次推断算法性能持续提高。可分别讨论“方法机制的演进”与“相同协议下的性能变化”；后者需要可比的实验或重新评测。
