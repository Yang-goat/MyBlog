基准测试通过规定问题、评价预算与统计指标比较求解方法，竞赛在此基础上组织提交与结果排名。

CEC（IEEE Congress on Evolutionary Computation）是演化计算会议，其竞赛包含不同的问题与评价协议。“CEC”是实验资料的组织入口，不是与约束优化、昂贵优化并列的研究方向。

按[年度资料](./cec-resources.md)查找题目和原始结果，按[赛道与算法演进](./cec-tracks.md)建立长期对比。同一算法的机制分析链接到[前沿算法与框架](../frontier-algorithms/)。
