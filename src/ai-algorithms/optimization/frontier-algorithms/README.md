优化算法框架通过组织模型、算子与评价流程形成求解方法，其有效性需要结合论文假设和实验条件理解。

## 阅读路线

| 路线 | 重点分析 |
| --- | --- |
| 自适应与混合算法 | 参数如何更新，多个算子或搜索器如何选择与协作 |
| 代理模型与多保真框架 | 如何建模、选择真实评价点并分配不同精度的预算 |
| 协同进化与分解框架 | 子问题如何划分、交换信息并评价联合解 |
| 学习辅助优化 | 学到了什么，训练成本如何计入，与手工策略怎样比较 |

每篇笔记链接原始论文、可用的作者代码和所属[研究方向](./research-directions.md)，记录创新机制、实验预算、消融证据与局限。基础机制可链接到现有算法家族文章，不必重新复制。

竞赛获奖事实及赛道条件放在[基准测试与竞赛](../benchmarks/)中，算法机制在此独立解释；阅读进展链接回[每周总结](/paper-notes/weekly/)。
