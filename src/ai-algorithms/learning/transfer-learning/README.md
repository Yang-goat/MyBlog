迁移学习利用源领域或源任务中的知识，帮助目标领域或目标任务的学习。

后续笔记可按领域适应、表示迁移与任务迁移组织，重点辨明源与目标的差异、可用数据，以及负迁移的条件。迁移学习与优化问题中的迁移搜索可在[优化研究方向](/ai-algorithms/optimization/frontier-algorithms/research-directions.html)交叉关联。
