# 阅读笔记与专题关联

周记记录阅读过程，专题笔记沉淀可以独立复用的方法与结论。同一篇精读只维护一份正文，从周记、研究方向或竞赛条目链接过去。

## 单篇精读的基本信息

| 字段 | 记录内容 |
| --- | --- |
| 论文 | 标题、作者、年份、发表来源、DOI 或原文链接 |
| 研究问题 | 优化什么，约束是什么，为什么已有方法不足 |
| 方法 | 关键机制、依赖假设，以及相较基线改变了什么 |
| 实验 | 数据或测试集、预算、基线、评价指标与实现版本 |
| 证据 | 对应的图表、章节或页码，以及结论的适用范围 |
| 我的理解 | 疑问、可能的解释、与自己研究的联系 |
| 关联 | 所属周记、研究方向、相关方法、代码或复现实验 |

正文分清作者报告的结论、自己的解释和实际复现结果。某个测试集上的优势不要直接写成普遍优势。

## 为知识图谱保留关系

从有证据的关联开始：论文“提出”方法，方法“针对”问题，实验“使用”基准，结果“支持”有条件的结论。方法之间的“改进自”或“组合了”关系需要原文依据。

优先用 DOI、原文链接和稳定的文章链接定位对象。相关问题与方法通过正文内链接建立引用，不通过分类标签或侧边栏交叉归档。
