论文随笔是围绕研究问题、方法与证据形成的阅读记录，用来连接单篇论文的理解与长期研究思路。

按周记录阅读进展，单篇精读与专题综述分别成文；周记链接到这些笔记，保留当时的疑问与后续修正。

## 从阅读到专题

| 阅读产出 | 适合记录的内容 | 后续去向 |
| --- | --- | --- |
| 每周阅读总结 | 本周问题、论文清单、共同发现、待验证想法 | 组会汇报与下一周阅读计划 |
| 单篇论文精读 | 方法机制、实验设置、结论边界、个人判断 | 对应领域的论文专题 |
| 专题对比 | 不同方法的关系、证据差异与研究空白 | 研究方向索引与知识图谱 |

领域入口：[优化研究方向](/ai-algorithms/optimization/frontier-algorithms/research-directions.html)、[优化前沿算法与框架](/ai-algorithms/optimization/frontier-algorithms/)、[强化学习前沿方法](/ai-algorithms/learning/reinforcement-learning/frontier-methods/)、[迁移学习](/ai-algorithms/learning/transfer-learning/)。
