# 赛博杂货铺

《赛博杂货铺》是一款暂停式经营网页游戏。你在城市下层街区接下一间小店，买卖生活用品与旧设备，学习修复手艺，听街坊讲述物品的来路，最终争取永久经营权。

<a href="/cyber-shop/">打开《赛博杂货铺》</a>

当前版本围绕修复师的四章旅程展开，包含经营权结局和通关后的自由经营。营业日由操作推进，思考时不会消耗工时。建议使用电脑，手机可横屏触控。

## 第一天怎么开始

新开局先看蒙版逐区介绍，最后点击高亮的《店长手册》阅读六章教程，再按右侧绿色按钮叫号。可以跳过区域介绍直接翻书，之后随时点击仓库用具格里的手册重读；目录可直接跳章，也可点击翻页或使用左右方向键。交易和维修窗口能直接翻到对应章节，合上后返回原操作。听完客人的需求后，把来货拖上谈判台，或点击对白中的操作按钮。上方来货属于客人，中间是谈判台，下方格子是自己的仓库。来货、谈判台、仓库和箱包内部使用同样大的正方形格子，物品图标按原比例放大，轮廓标出实际占格，旋转后同步改变朝向。电钻、三通阀和折叠检修灯带有可以嵌放小件的凹角，整理时可以利用这些空位。

箱包需要向来访 NPC 购买。腰包、快递员背包、工业周转箱和重型货运箱有不同外形、内部格子和价格，买下后先留在谈判台，再安排位置。箱包本身也占格，可以箱中套箱、包中套包；双击后在鼠标附近打开格子小窗，双击内部箱包可继续打开，仓库始终可见。最多三层，最外层算第一层；可拖动窗口标题栏，跨窗口拖放物品。整只搬动会带上内部物品，取出时仍要有完整空位。标签机可以命名、配色，把待修、待售和收藏分开；空箱包也能卖给买家。具体操作可翻阅《店长手册》的“库存与收藏”一章。

普通开局保留 144 格仓库。标题页的“开局词条”提供 11 个正向帮助与负面挑战，改变资金、仓库、租金、每日工时、批发门槛或食品保质期。例如“批发熟客”两件起九折，“零售货源”取消批发优惠；“临期货源”则需要更快售出或及时保鲜。同类词条互斥，选择会随本局保存；不选词条即按标准规则营业。

卖家每批带来的旧货各有品相、故障与价签，检查一件不会揭示其他货物。查看信息后，再决定直接成交、议价或拒绝。可以只买一件，也可以选择多件；标准营业同次买入至少三件享九折，开局词条可改变这一门槛。付款后货物仍留在台面，拖进仓库或点击“全部入库”收好。买家有自己的品类需求和预算，选中的货物超出预算时，可使用“按预算挑选”，余货留待下一笔生意。

交易窗口左侧挑货和检查，右侧核对清单与价格。报价不合适时，客人会给出针对当前货品的还价，可以直接接受，也可以继续谈。合理报价会带来小幅让步，相差过远则维持原价；每位客人的耐心有限，谈不拢时现金与未成交货品保留。换了一批货要重新报价。每次成交会留下小票，售出时可以对照实际货款与累计货品成本，判断这笔生意的差额。

右侧的九街通讯显示当天行情。街区停电、修缮或庆典会影响相关商品价值；点击通讯可以阅读事件并决定如何回应。

仓库物品可拖动，也可点选后点击空格放下；异形物品可用 `Q` 逆时针、`E` 顺时针四向旋转，`Esc` 取消。鼠标悬停显示价格与已知信息，右键打开物品菜单；触屏点选查看详情，长按打开菜单。谈判台可以临时存放自有货物，方便腾挪仓库。

接到维修委托后，先做检测，再按读数处理故障：擦净六个接点、松开螺丝更换模块，或者调整校准信号。准备操作不消耗工时，确认执行时显示并结算实际费用；也可切换“参数操作”，或在熟练后使用快捷工序。完成维修后复检，确认通过再交付。客户的材料预付款只用于对应工单；即使手头没有现金，也可以接基础援助维修重新积累收入。

交付后的工单会进入“修复档案”，保留收件和交付日期、前后品相、实际工序与报酬，最近 80 件可以随时翻阅。当天没有修完的东西，可以第二天接着处理；回头客也会提起尚在工作台上的物品或已经取回的旧物。

执行前的结算预览会列出工时、材料来源和实际花费。自有旧货优先取用库存耗材，缺料时才用现金补充；客户工单使用各自的专款。古董可以比较更换模块和修整原件的代价，精密校准技能与校准仪则会扩大读数容差，当前范围显示在操作台上。

工时用完，或当天安排已经完成时，清空谈判台后闭店。日结账单列出维修收入、售货收入、采购与培训、租金和维护费；现金净变化包含尚未售出的库存采购，并不等同于利润。未完成工单保留到明天，下一营业日恢复工时并刷新来访与街区事件。

费用不足会形成欠费，任务板随即优先引导补救，账单标出下次应缴金额和最后期限。例如第一天闭店首次欠费，仍可在第二、三、四天经营，需在第四天闭店前备足费用；基础援助维修使用客户专款，可以零现金接单。凑够费用后完成日结，才会消除欠费。停业时可以恢复当天开门备份，重新安排这一日。

## 给街坊备一份货

库存页、任务板和街区手记都能打开订货簿。每天有三份来信，同时最多承接两份；接取免费，货款和交期事先写明。十二种订货覆盖六类商品，例如为工坊挑两组有效容量达标的电池，或替放映社找有合法授权的影像载体。

先按用途核对型号、品相和特殊条件。没有检查的属性仍需检查，扫描仪或序列终端也要实际持有。挑出合格的自有货品后装箱，花半个工时交付，收取整单货款；页面同时列出选中货品的累计成本。食品按交货当天的剩余保质期验收，可以在适用时使用保鲜包。

交货完成后，货品离开库存，订货人的回信和交货清单留在簿中。期限以最后一天闭店为界，超期或主动取消都会保留尚未交付的物品与现金；次日还有新的需求可以选择。

## 六类商品如何取舍

| 商品类别 | 买卖时关注什么 |
| --- | --- |
| 民用与工业机电 | 功能故障、成色、体积与修复成本 |
| 能源与工业材料 | 有效容量、纯度、批次与当天行情 |
| 食品与生物制品 | 剩余保质期、保鲜投入与临期折价 |
| 神经与医疗器件 | 型号兼容、来源和受管制商品交易许可 |
| 数据与娱乐载体 | 完整度、可读性、授权来源与收藏需求 |
| 古董与奢品 | 真伪、出处、品相和原始部件价值 |

六类普通商品从早期就进入货池，高级款逐步开放。普通合法商品可以买卖，专业加工则取决于资质。数据载体修好接口之后，缺失内容不会自动补回；古董更换原始部件，也可能改变它的收藏价值。

## 修复、成长与收藏

通用树和维修树共用技能点。通用技能改善交易、货源、仓储和陈列；维修树分为精准维修、效率工坊、翻新收藏三条方向。主线需要集中投入，形成一项大师能力。

完成开店引导后，左侧任务板显示当前目标。点击“查看下一步”，可以查看四章进度、直接前往所需功能，并领取已完成街区委托的谢礼。章节推进依次要求维修案例、工业资质、神经资质，再到大师能力与最终委托。

街区手记里的委托卡会标出具体进度，也能直接前往相关功能。每次领取阶段谢礼后，委托人会留下一封回信；四条故事分别留下邻里支持书、工坊铭牌、旧城散步图和夜班联络卡。当天选择的街区行动也会留在通讯中，刷新后可以继续查看。

民用电子资质开局具备，工业设备和神经接口资质需要案例积累、培训与实际考核。维修证书与交易许可分别管理：会修一件设备，并不自动获得受管制商品的交易资格。

工具采购会显示持有状态、实际花费和购后余额。耗材可以按 1、5、10 份补充，学会快捷补货后自动享受优惠。自有旧货翻新先消耗库存材料，客户工单则使用各自的材料专款。取得微焊工具、装配夹具和校准仪后，它们会出现在维修台上；检测屏也随故障排除和复检变化。

已鉴定的自有真品可以进入展示柜。起初有三个位置，增设展柜后可在两层摆放六件旧物。展品退出普通售卖，撤展后再回到货架；品类搭配、原貌与主题组合会影响吸引力。客户送修物始终属于客户。

## 经营权与通关后

取得大师能力、完成联络中枢的多阶段修复，再支付经营权收购款，就能完成主线。结局可以保存，也可以继续无尽经营。

继续经营保留资产、资质、技能与收藏，并永久免租。古董科技考核、新来访者和可选挑战随后开放，经验仍会产生技能点。合成工匠、能源技师、生态培育者、数据经纪人和遗物策展人的专业加工属于后续方向。

## 保存与换设备

游戏使用浏览器本地存档，并保留营业日开始备份。刷新后可继续进度，失败时可恢复当日备份重新安排经营。

`F` 切换全屏，`Esc` 关闭面板。设置中可调整音量、关闭街区环境音或减少动态效果，这些选择会在本机保留。店内的窗外街景、雨水、灯光、柜体与设备分别呈现，场景动画不会让经营时间自行流逝。

换浏览器、换设备，或从本机迁移到正式站点前，先在游戏内导出存档；到目标环境后导入。不同地址的浏览器存储彼此独立。损坏或版本不兼容的文件会提示错误，应保留原文件。

导出文件保存当前进度，不携带原站点的当日开门副本。导入后可恢复到本次导入点；从下一个营业日起，再按当天开门时的状态备份。

当前价格、工时、费用与成长速度仍会根据试玩调整。自动化测试已经从新开局走通四章、保存结局并继续经营，实际人工游玩时长取决于阅读、整理与经营选择。
