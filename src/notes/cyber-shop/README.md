# 赛博杂货铺

《赛博杂货铺》是一款暂停式经营网页游戏。你在城市下层街区接下一间小店，买卖生活用品与旧设备，学习修复手艺，听街坊讲述物品的来路，最终争取永久经营权。

<a href="/cyber-shop/">打开《赛博杂货铺》</a>

当前 Demo 围绕修复师展开。营业日由操作推进，思考时不会消耗现实时间。建议使用电脑，手机可横屏操作。

## 第一天怎么开始

先接待柜台前的访客。卖家带来商品时，查看信息与检查结果，再决定直接成交、议价或拒绝。买家有自己的品类需求，从自有库存中选出合适商品即可报价；每位客户的耐心有限。

接到维修委托后，先做检测，再按读数选择清洁、模块更换或参数校准。完成工序后复检，确认通过再交付。客户的材料预付款只用于对应工单；即使手头没有现金，也可以从基础委托重新积累收入。

工时用完，或当天安排已经完成时，可以闭店结算。闭店扣除租金与维护费，下一营业日恢复工时并带来新的来访与事件。

## 六类商品如何取舍

| 商品类别 | 买卖时关注什么 |
| --- | --- |
| 民用与工业机电 | 功能故障、成色、体积与修复成本 |
| 能源与工业材料 | 有效容量、纯度、批次与当天行情 |
| 食品与生物制品 | 剩余保质期、保鲜投入与临期折价 |
| 神经与医疗器件 | 型号兼容、来源和受管制商品交易许可 |
| 数据与娱乐载体 | 完整度、可读性、授权来源与收藏需求 |
| 古董与奢品 | 真伪、出处、品相和原始部件价值 |

六类普通商品从早期就进入货池，高级款逐步开放。普通合法商品可以买卖，专业加工则取决于资质。数据载体修好接口之后，缺失内容不会自动补回；古董更换原始部件，也可能改变它的收藏价值。

## 修复、成长与收藏

通用树和维修树共用技能点。通用技能改善交易、货源、仓储和陈列；维修树分为精准维修、效率工坊、翻新收藏三条方向。主线需要集中投入，形成一项大师能力。

民用电子资质开局具备，工业设备和神经接口资质需要案例积累、培训与实际考核。维修证书与交易许可分别管理：会修一件设备，并不自动获得受管制商品的交易资格。

已鉴定的自有真品可以进入展示柜。展品退出普通售卖，撤展后再回到货架；品类搭配、原貌与主题组合会影响吸引力。客户送修物始终属于客户。

## 经营权与通关后

取得大师能力、完成联络中枢的多阶段修复，再支付经营权收购款，就能完成主线。结局可以保存，也可以继续无尽经营。

继续经营保留资产、资质、技能与收藏，并永久免租。古董科技考核、新来访者和可选挑战随后开放，经验仍会产生技能点。合成工匠、能源技师、生态培育者、数据经纪人和遗物策展人的专业加工属于后续方向。

## 保存与换设备

游戏使用浏览器本地存档，并保留营业日开始备份。刷新后可继续进度，失败时可恢复当日备份重新安排经营。

换浏览器、换设备，或从本机迁移到正式站点前，先在游戏内导出存档；到目标环境后导入。不同地址的浏览器存储彼此独立。损坏或版本不兼容的文件会提示错误，应保留原文件。

导出文件保存当前进度，不携带原站点的当日开门副本。导入后可恢复到本次导入点；从下一个营业日起，再按当天开门时的状态备份。

当前价格、工时、费用与成长速度用于试玩，首次通关约两小时是节奏目标，实际体验仍需持续检验。
