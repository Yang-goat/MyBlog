海克斯麻将是在实体四人麻将基础上加入强化、契约、世界事件和可选派对模块的玩法。本栏目提供电子卡牌主持台、快速上手说明、完整规则与 192 张卡牌资料。

## 开始游玩

<a href="/hex-mahjong/">打开海克斯麻将主持台</a>

主持台适合将平板横放在桌面中央使用。它负责抽取电子卡牌、记录执行状态、八局进度与四名玩家的手动净分；实体麻将的手牌、牌墙、吃碰杠胡和合法性仍由玩家自行处理。

第一次游玩建议先阅读[快速开始](./quick-start.md)，并选择策略模式熟悉流程。
