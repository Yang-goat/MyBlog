检索增强生成（Retrieval-Augmented Generation，RAG）在生成回答时引入检索得到的外部信息，为模型提供相关上下文。

专题按数据处理、索引与检索、重排、上下文组织及效果评价展开；涉及图结构检索的方法可同时关联[知识图谱](../knowledge-graphs/)。

检索模块可以作为[Agent](../../agent-systems/agent-design/)调用的工具，长期交互信息的写入与更新则放在[记忆系统](../../agent-systems/memory/)中讨论。
