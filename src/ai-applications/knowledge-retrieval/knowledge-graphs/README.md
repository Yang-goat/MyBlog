知识图谱用实体、关系及其属性表示知识，使分散的信息能够按语义关联、查询与推理。

专题可从实体与关系建模、知识抽取、实体对齐和图查询展开。文献图谱中的论文、方法、问题与证据关系，可以从[阅读笔记](/paper-notes/reading-workflow.md)逐步积累。

知识图谱也可以参与[RAG](../rag/)的检索，或支持[记忆系统](../../agent-systems/memory/)的信息组织；交叉方法使用链接关联。
