Agent 设计研究如何组织感知、规划、工具调用与反馈，使智能体能够围绕目标执行任务。

专题关注任务分解、执行循环、状态管理、多智能体协作和效果评价。客户端的安装配置见[Agent 客户端与工具](../../tools-practice/agent-clients/)。
