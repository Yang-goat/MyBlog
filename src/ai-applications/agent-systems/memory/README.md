智能体记忆系统管理交互历史、任务状态与长期知识，并决定信息何时写入、检索、更新或遗忘。

专题关注工作记忆、情景与语义信息、记忆压缩、冲突处理及记忆效果的评价。持久化存储只是其中一个环节。

记忆可使用[RAG](../../knowledge-retrieval/rag/)进行召回，也可用[知识图谱](../../knowledge-retrieval/knowledge-graphs/)组织关系；这些机制如何进入任务执行流程，见[Agent 设计](../agent-design/)。
