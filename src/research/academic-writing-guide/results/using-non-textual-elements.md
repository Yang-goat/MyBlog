# 使用非文本元素

## 常见非文本元素的定义

**图表（chart）**　参见下文“统计图（graph）”。

**图形或数字（figure）**　这个英文词可以指由三条或更多条线围成的形状，也可以指表示一个数的一个或多个数码或数字符号。

**流程图（flowchart）**　以图示概括一项程序或一个过程从开始到结束所涉及的决策和信息流动，也就是用图形来表达算法。英文中也称 *flow diagram*、*flow process chart* 或 *network diagram*。

**统计图（graph）**　用直线、曲线、一组条柱或其他符号，在二维平面上表示关系，通常是两组数值之间的关系。一般把自变量放在横轴（X 轴），因变量放在纵轴（Y 轴）。两条坐标轴互相垂直，交点称为原点；各轴按所表示的量及其单位标出刻度。两轴通常把平面分成四个象限，对应变量取正值、负值的不同组合。当变量没有负值，或者研究不关注负值时，通常只画右上方的第一象限。*Graph* 和 *chart* 两词在英文中常可互换。

**直方图（histogram）**　用阶梯状的柱形概括一组数据在不同区间内的频数分布。每个区间称为一组（class），由下限和上限界定。横轴（X 轴）表示各组，纵轴（Y 轴）表示各组出现的次数或所占百分比。作图时，在横轴上画出彼此紧邻的矩形，矩形的面积与相应组的频数成比例。原页称，直方图和频数分布折线图（histograph）常用于描述离散量，例如一所学校的学生人数，并以学生身高的变化为连续量的例子。直方图也称频数图（frequency diagram）。按原页的说法，组数少于八组时，通常优先采用直方图。

**插图（illustration）**　用图片或示意图把论文中的某个主题呈现得更生动，或让读者更容易理解。

**地图（map）**　以视觉形式呈现某一区域，用符号突出空间中不同要素之间的关系，如事物、地区以及与特定主题有关的要素。常见类型包括气候图、经济图、资源图、自然地理图、政区图、道路图和地形图。

**象形统计图（pictograph）**　用图标、图片或符号替代常用的统计图元素（条柱、线、点），或者将两者结合起来呈现数据。读者可以通过相同图形的相对大小或重复次数比较数量。英文中也称 *pictogram*、*pictorial chart*、*pictorial graph* 或 *picture graph*。

**符号（symbol）**　用来指称、表示某个概念、事物或关系的标记、记号或词语，也包括人们通常理解为具有这类代表意义的标记。

**表格（table）**　把定量数据按行、列有序排列，也称矩阵（matrix）。

## 为什么要使用非文本元素

在论文中加入非文本元素，有以下几方面的理由。

1. **一图胜千言。** 有些研究发现需要用好几段冗长、乏味的文字才能说清。在研究论文中嵌入图表、插图、表格、统计图、地图或照片，可以简明地报告这些发现，使研究更容易理解。
2. **便于汇总信息。** 要呈现的数据很多时，非文本元素尤其有用，读者可以迅速而有条理地掌握大量数据。
3. **在保持行文连贯的同时突出重要信息。** 插图、照片和地图等可以供读者随时查阅，让正文讨论的关键问题更加突出。例如，一项研究记录贫困家庭寻求适当医疗服务时遇到的困难，其中可以用一张街道地图标出医疗机构的分布。
4. **吸引读者的目光。** 一张图表或照片可以改善研究的整体呈现效果，也能引起读者对这项研究的兴趣。

## 结构与写法

用图、表、统计图等非文本元素支持关键研究发现。读者应当能够单独读懂每一项图表。图表本身要简明，标注要整洁、清晰，图表说明要用完整的句子把内容解释充分，让读者无需另查正文。正文也应能独立读懂，避免让读者为了理解论文而在文字与图表之间反复翻找。

**在研究论文中使用非文本元素时，遵循以下通则。**

- 每一项都必须有说明，包括编号和标题。
- 选定合适的图表说明格式，并在全文中保持一致。
- 可以把图表插在正文中，也可以统一放在论文末尾。两种安排应择一使用。
- 如果统一放在论文末尾，要让读者能把这些图表与附录材料清楚地区分开来。
- 正文提到图、表或统计图时，应写出具体编号，避免使用“见下页图表”或“如下表所示”等说法。
- 如果把图表插在正文中，应尽可能靠近首次提到它的位置。
- 正文必须对其中出现的每一项图表有所说明，必要时应给出清晰的解释。
- 各项非文本元素的外观应当统一。可以采用以下做法。
  - 用方框或边框围住图表。
  - 图表文字采用与正文不同的字体，例如图表用 Arial、正文用 Times New Roman。
  - 英文标题可采用小型大写字母（small caps）。
  - 避免使用花哨的字体。
- 如果某项非文本元素完全由你自己制作，请明确注明。凡是取自其他来源或据其他资料改编的，都必须注明原始出处。

在正文中指引读者查看图表时，通常把指引放在括号里，例如“（见图 1）”。图表中的信息通常是对结果本身的补充，正文的主要篇幅应放在重要的研究发现上。

**注意用量。** 只有当图表能够有效充实或补充论文已叙述的信息时才使用，并应有所节制。图表过多会打断行文，增加读者综合理解和解释整项研究的难度。如果确实需要用到许多图表，可以考虑把它们集中编入附录。
