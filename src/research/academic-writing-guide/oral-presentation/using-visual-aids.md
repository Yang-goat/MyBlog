# 使用视觉辅助材料

## 怎样有效地使用 PowerPoint

1. **每张幻灯片至多讲三四个要点。** 满屏文字很容易让听众失去兴趣。幻灯片可以补充讲解，让你说的话更容易理解，讲解本身仍得由你来完成。
2. **给听众留出看幻灯片、记笔记的时间。** 讲下一个要点之前，你也可以利用停顿整理思路。
3. **确保听众能看见屏幕。** 留意自己的站位，别挡住屏幕。如果站在哪个角度都会遮住一部分听众的视线，就在换页前走动一下，例如走到一旁，指给大家看你要强调的内容。
4. **控制每页的细节。** 配色、图片和图表能让幻灯片更有意思，但有些颜色搭配从远处看很难辨认。
5. PowerPoint 做得再漂亮，也可能遇到设备故障。**最好事先印好讲义，或备几张传统投影仪用的透明胶片**，以备不时之需。
6. 你可能很想多花些时间制作 PowerPoint 图形，结果准备讲解的时间反而少了。请记住，**讲得不好，再华丽的图形也救不了这场报告。**

## PowerPoint 幻灯片的文字排版

- 全套幻灯片使用统一的配色和字体，选用风格一致的图像。
- 背景保持一致，宜选不抢眼的样式。
- 一般来说，每行英文不超过六个词。
- 每张幻灯片一般不超过六行文字。
- 避免长句。
- 用较大的字号标示更重要的信息。
- 字号一般在 18 至 48 磅之间。
- 确保文字与背景有足够的对比度。
- 花体字可能很难辨认。
- 全部用大写字母拼写的英文单词不易阅读。
- 避免使用缩写和首字母缩略词。
- 少用标点符号。

## 讲义

听众人数不多时，发讲义是个好办法；听众太多，分发讲义就可能花去不少时间。事先想好是在报告前还是报告后分发。最好把参考资料列在讲义上，听众日后可以查阅。还可以附上几个供后续讨论的问题。

## 使用白板

如果条件允许，在报告开始前就把联系方式写在白板上。临时转身去写会背对听众，中断目光交流，应尽量避免。板书也很花时间，能用其他视觉辅助材料时，尽量用其他材料。如果确实需要用白板，事先带好合适的白板笔，把字写得大而工整，让听众看得清楚。

## 熟悉场地

报告前，到教室前面站一站，从讲者的位置熟悉整个房间。站在前面和坐在平时习惯的座位上，感受很不一样。也要事先检查照明，免得到开讲时还得忙着调灯光。
