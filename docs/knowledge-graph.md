# 本站知识图谱维护

图谱入口是“AI 应用 → 知识与检索 → 知识图谱 → 本站知识图谱”。图谱只在该文章挂载，普通文章不加载图谱数据或交互引擎。

## 收录与关系

图谱收录 AI 与算法、AI 应用、软件工具、随笔、论文随笔五个栏目的公开正文文章。目录页、首页、个人介绍、英文入口、测试页、自动页面以及展示图谱自身的文章不参与建图；草稿、非文章和受访问限制的内容不进入公开数据。

实线表示正文中的站内引用，方向为引用文章指向被引用文章。虚线表示文章具有某个主题标签。关系来自实际 Markdown 链接和 `tag`，不推断算法继承、因果或语义相似。同一目标的多次引用合并；代码块、图像、外部网站、自动导航和目录不产生正文引用关系。

新增文章不需要手工登记节点。VuePress 构建时提取页面与元数据，输出图谱模块；开发环境新增、修改和删除文章后也会更新。节点跳转采用 VuePress 的实际路由，已有重定向别名只用于解析引用，不重复建点。

## 标签与正文维护

标签优先描述文章实际涉及的领域或知识点，避免只有“教程”“理论”等体裁标签。中英文和缩写是否合并应按上下文判断，不通过目录名称自动赋予标签，也不为连接孤立文章添加无依据的主题。

通用标签的排除规则在 [`config.mjs`](../src/.vuepress/knowledge-graph/config.mjs) 中集中维护。排除仅影响主题节点，不删除文章原有标签。默认显示至少关联两篇文章的主题；关闭“仅共享主题”后可以查看单篇主题。

补站内链接时，用自然出现的原有词句链接相关正文；优先使用相对 Markdown 路径。同一目标通常只在首次有意义的位置链接一次。不要把标题、公式、代码、图片或已有链接内部再次包装为链接。

本次初始整理记录见[内容审计](knowledge-graph-content-audit.md)和[变更清单](knowledge-graph-content-changes.json)，实际测试见[首版验收记录](knowledge-graph-validation.md)。清单保存本次标签和补链操作，正文保护检查撤销已登记的链接包装后核对原始正文、编码和其他元数据。

## 界面与加载

单击节点查看预览，使用“打开文章”在新标签页阅读。搜索覆盖标题与主题，选择被筛选隐藏的结果会清除冲突筛选。文章列表提供键盘和手机访问入口。

普通状态滚轮滚动页面，按住 Ctrl 缩放图谱；全屏时直接滚轮缩放。全屏优先使用浏览器接口，不可用时使用页面内全屏。退出、切换路由和卸载组件时释放事件与滚动锁。

初始位置在构建时通过固定步数的力导向布局计算，并使用稳定顺序及随机源。浏览器无需持续运行物理模拟；拖动只调整当前显示位置。栏目颜色、节点形状和两类线型共同表达含义。

图谱数据具有内容指纹；视图状态仅保存于当前浏览器会话。数据变化后会舍弃不再有效的选择。预览始终按纯文本渲染，不执行文章中的 HTML。

资源加载失败时提供“重新加载页面”，刷新文档以清除浏览器对失败模块的缓存，已保存的会话状态保留。只要数据资源成功返回，即使交互引擎失败，也会提供可直接打开文章的列表。

## 检查与交付

项目构建、结构校验和搜索回归命令见[项目维护](maintenance.md)。图谱额外检查：

```powershell
pnpm.cmd graph:test
pnpm.cmd graph:content
pnpm.cmd graph:check
```

`graph:check` 在 `docs:build` 之后执行，核对图谱统计、未解析链接诊断及生成的文章 HTML，确认节点都有真实路由、连线两端均存在。生成数据和诊断位于 VuePress 管理的 `src/.vuepress/.temp/knowledge-graph/`，不能手工修改或提交。正文保护检查面向本次整理记录；后续有意改写这些文章时，应按新的修改范围重新建立审计基线，不直接关闭检查来掩盖差异。

交互验收覆盖搜索、筛选、预览、跳转、共享主题开关、聚焦/返回、列表、缩放拖动、状态恢复、原生及降级全屏；覆盖明暗主题及桌面、窄屏和手机宽度。另抽查普通文章和原有分类思维导图，确认不存在样式或全屏状态残留。
