环境：Windows、本机 Chrome 153、Playwright；生产静态预览端口 4173，无网络或 CPU 限速。视口为 1440×1000、1024×900、390×844，额外使用支持触摸的移动端模拟上下文。并非真实 iOS/Safari 或低端手机实测。

| 预览与关联 | 显示正文首段及标签，引用/被引用/主题列表可继续定位 |

Theme Hope 原有页面预取可能请求图谱展示文章的轻量页面模块；该模块不启动图谱，不下载数据或 D3 交互引擎。后两者在图谱组件挂载后才加载。

性能抽测：图谱就绪标记约为导航后 229–243ms。浏览器切到前台后，以输入/切换事件至后续两个动画帧测量：三次搜索约 6.6–13.2ms，三次共享主题切换约 11–33.5ms。满足本机首版目标，不能推断线上或所有手机的耗时。此前自动化页面未置前时动画帧等待受浏览器调度影响，未将该样本作为前台交互指标。

## 环境限制与后续维护

构建首次曾遇到 Windows 沙箱阻止 esbuild 子进程的 `spawn EPERM`，授权执行后通过。依赖声明期间遇到本机 pnpm 存储路径及可选依赖安装状态问题，已使用原锁文件和既有缓存恢复；未更改全局配置。Git 的部分 LF→CRLF 提示对应文章原有换行格式，正文保护核验已确认原始字节保持。

浏览器抽查原有思维导图页时，Giscus 对尚不存在的讨论返回 404 和提示；与图谱无关，图谱展示页已关闭评论。没有发现图谱运行异常。

新增文章、标签或正文链接会在构建/开发监听中自动进入图谱。通用标签排除、故障诊断和检查命令见[维护说明](knowledge-graph.md)。本地截图、完整构建日志和开发生命周期记录随本次交付保存；生产预览服务保持可用。
