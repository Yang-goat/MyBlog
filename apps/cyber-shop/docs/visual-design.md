# 雾港第九街的视觉方案

玩家从雨中的街角走进一间暖灯还亮着的旧物店。街景、设备和帐本来自同一个地方。用磨损边缘、灯光和纸张区分它们的用途。用核心操作和角色对话带玩家进入经营，标题页只保留开局、存档和设置所需的文字。

方案参考 `ui-ux-pro-max` 的 3D & Hyperrealism、Cyberpunk UI 与键盘焦点条目。应用其中的材质深度、冷暖光和可读的操作状态。Vue 栈查询未命中相关条目，沿用项目现有结构，由 Canvas 绘制室内外空间，Vue 负责可点击的物件和面板。

| 用途 | 视觉规则 | 应用 |
| --- | --- | --- |
| 雨夜街区与店内设备 | 深墨蓝 `#09131c`、旧钢蓝 `#13242e`，少量反光勾勒边缘 | 封面阴影、窗框、面板、箱包小窗 |
| 选中与设备读数 | 浅青 `#a6e4da`，配合边框与实际选中状态 | 商品与工序选中、输入焦点、终端 |
| 经营动作与当前分区 | 暖铜 `#efc08a`，配深色文字 | 开店、交易确认、仓库当前页 |
| 店主留存的纸面 | 暖纸 `#eee0c4`、深墨 `#352e26` | 《店长手册》、行情便笺、日结 |

标题、手册和结局用本机宋体或衬线后备字体。经营文字继续用易读的中文界面字体，金额用等宽数字。键盘焦点使用独立描边，格子内缩描边，以免被边界裁切。手册页内焦点采用纸面深色。短反馈使用颜色和阴影，翻页及场景动效遵循减少动态设置。

窗外收货架使用冷色镀锌钢，边沿有排水槽。桌上交易区是黄铜包边的胶垫。桌下仓库用暗色凹槽、侧壁和下沿导轨表现深度。三块背板沿实时格子边界绘制，收纳箱包与货区共用格长。街景按实际视口裁切，雨丝和湿路反光单独绘制。杯子、盆栽是独立透明素材，贴地影和杯口蒸汽由场景绘制。原始图、运行时 WebP 及校验信息在 [scenery-manifest.json](../scenery-manifest.json) 登记。

谈判沿用店铺设备的墨蓝板面、青色选中线和暖铜结算按钮。人物、身份、教程入口位于页首，货品数量与报价落在对应的托盘或清单。矮横屏也保留商品与结算两列，商品列表改为单列，留出商品名和品相的空间。成交回执、订货回信和日结沿用暖纸。横屏顾客对话把正文和操作分开，长台词在正文内阅读，交易入口固定在下沿。议价提示随对话记录一起阅读。

新增界面先使用 [ninth-street.css](../src/ui/ninth-street.css) 的共用色值和控件状态，再选择与具体用途相符的材质。需要移出场景层的窗口挂载在游戏根节点下的 `#shop-overlays`，继承配色、键盘焦点和减少动态设置。检查 1440×960 桌面、844×390 和 568×320 横屏手机及 375px 竖屏标题。仓库与箱包格子完整显示，触屏保留点选放置和撤销，纸本正文可在页内阅读。
