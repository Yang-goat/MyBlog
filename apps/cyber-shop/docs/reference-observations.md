# 店铺交互观察 · 2026-11-05

来源：通过 computer-use 实际打开用户屏幕 1 上的 Probably Stolen（VERSION 100-REV6），创建学徒、普通难度的新游戏，保留开场。不是完整通关记录。

## 已看到的设计

- 开局依次选择专精、初始特性、难度；学徒有启动资金、储藏设备与初始库存。特性有点数与数量限制，难度列出经济参数，并可选择跳过开场或无尽模式。
- 店铺是一个连续空间：中央门外站顾客，门槛是来货区；近景横向桌面是谈判柜台；下方常驻二维格子仓库；左侧展示柜和电话；右侧营业按钮、排队人数、终端、录音设备与睡袋。现金、日期、租金期限放在墙面设备中。
- 初次进入先展示场景热点及快捷键提示。导师进店说话并留下交易笔记；文档右键有阅读选项，可在店内展开。不同操作阶段出现局部提示。
- 交易笔记说明：物品拖到谈判柜台后打开谈判界面；顾客消费预算有限；出售自动计入零售加价。
- 第二位拾荒客先说话，随后把数件食品放在门外。商品提示区分未拥有物品，显示类别、估值、基础价值、用途与背景。
- 对白可配置打字机效果、速度、音量和自动播放；关闭自动播放后显示空格推进提示。
- 界面明确提示支持框选多件、Ctrl 快速转移、Shift 转移展示柜、Alt 转移柜台，以及拖动物品时 Q/E 旋转、F 翻转。
- 用户补充并确认的关键流程：**店外来货区 → 谈判柜台 → 购买 → 自有仓库**。未购买货物不能直接收入自有仓库。

## 观察边界

已操作新游戏设置、开门、呼叫导师与拾荒客、推进对白、阅读交易笔记及查看商品详情。自动化拖拽多次未改变物品位置，因此尚未验证原游戏的成交、旋转、格子碰撞与日结行为；不将屏幕提示当作全部实测通过。后期系统和完整剧情尚未体验。

## Demo 对照与本轮方向

旧版的主流程是场景插图加右侧表单，仓库只有弹窗列表和容量数字；人物开场主要落在提示消息中。需要改成围绕实际物品位置操作的店铺。

视觉：保留原创雾港美术，使用连续店内空间、旧金属台面和清晰格子；顾客与货物为主体。

内容：先认识店铺 → 移动物品 → 对话与接待 → 谈判和购买 → 入库 → 维修与日结；详细资料按需打开。

交互：可见落点与碰撞反馈、逐段人物对白、按完成动作推进的引导；保留减少动态选项。

本轮优先补齐主布局、仓库摆放、来货/柜台/库存所有权流程、对白与可恢复新手引导。原游戏的特性系统、框选多货联合议价及生活需求属于后续设计范围，不能宣称已复刻。
