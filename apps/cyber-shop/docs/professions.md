# 六职业设计与首版边界

《赛博杂货铺》的长期目标是让同一间店通过资质、技能和设备逐步拓展业务。职业注册在 `src/content/progression.ts`，玩家没有永久锁定的开局职业字段。首版仅修复师具有完整动作、成长与结局，其他职业的商品进入通用交易系统，专业加工能力留待后续实现。

| 职业 | 当前可用范围 | 后续专业能力 |
| --- | --- | --- |
| 修复师 | 客户维修、自有旧货翻新、证书考核、古董技术修复、职业最终委托 | 增加设备和案例，不另建库存或资金系统 |
| 合成工匠 | 工业材料和设备交易 | 拆解、配方制造、定制 |
| 能源技师 | 按容量、纯度和行情交易能源材料 | 充能、提纯、混配 |
| 生态培育者 | 食品、生物制品交易及基础保鲜 | 培养、性状筛选、批量生产 |
| 数据经纪人 | 数据载体买卖、受修复资质支持的载体硬件维修 | 授权内容恢复、解密、信息服务 |
| 遗物策展人 | 自有真品鉴定、陈列、主题收藏与交易 | 深度考据、正式展览、私人拍卖 |

## 修复师

盈利循环是接收描述、检测、判断故障、选择工序和耗材、修复、复检、交付。客户工单赚取服务费；自有旧货记录购入和修复成本，再通过出售或陈列回收投入。证书扩大可维修品类，交易许可单独决定受管制商品能否买卖。

三条成长分支分别解决不同经营问题：精准维修降低检测与复检工时、放宽校准容差并提高高阶服务价值；效率工坊减少材料和工序投入、解锁重复故障快捷处理；翻新收藏改善收购判断、回收自有零件并提高恢复后的品相与交易价值。大师能力要求分支前置和足够的维修树投入。

对应商品包括通讯器、工业传感器、诊疗仪和古董机械件。微焊工具、装配夹具、校准仪提供工序能力，工作台改善作业效率。林桥带来街区小修，贺津提供工造考核，宋宜关注器械记录；通关后沈雾提出更高阶的精密需求。

修复师恢复物理功能。载体恢复通电不代表数据内容已经恢复或解密；古董恢复功能不代表完成历史考据。客户要求保留原貌时，原始部件的损失必须进入验收条件。

## 合成工匠

核心循环为买入材料、检验批次、选用配方、安排加工、检查成品、按订单或零售出售。利润来自材料组合、工序安排和定制需求；拆解产生可追溯的材料批次，投入和回收量必须守恒，不能让制造与拆解来回转换成为无成本利润。

商品以高导合金板、绝缘纤维卷、催化芯和标准机电模块为基础。后续设备包括微型合成炉、模具台和部件检测架。贺津需要稳定批次的工坊零件，祁岚提供材料，陆澈可能订制轻量收纳或运输设备。

三条分支：

- **材料利用**：识别批次、拆解分选、减少边角料。
- **配方工艺**：掌握新配方、稳定成品品质、生产复合组件。
- **订单定制**：读取用途约束、调整部件规格、完成高价值小批量定制。

通用货源技能影响材料采购，库存与经营技能约束在制品空间，交易技能影响成品成交。修复师将现有设备恢复到可用状态；工匠通过配方产生新的商品实例。两者可共享材料，但必须使用不同动作与成本记录。

接入时向 `PROFESSIONS` 注册已实现能力，向 `RECIPES` 增加配方，添加带版本的生产工单与 `craft` 动作。配方输入逐一扣除已有实例或材料数量；输出分配新实例 ID。技能与最终里程碑复用通用职业胜利入口。

## 能源技师

核心循环为检测剩余容量或纯度、购买低效原料、选择充能或提纯工艺、投入能源与耗材、稳定化复检、向适配客户出售。盈利来自有效容量和可用纯度提升，能源投入、电费、损耗与容器都计入真实成本。

标准电池组、电容阵列、便携电源模块与催化芯是主要商品。后续设备为可调充能架、密闭提纯器和安全负载箱。工坊、夜班诊所和互助社应急站分别需要连续供能、稳定波形与可靠备用容量。

三条分支：

- **充能管理**：判断电芯寿命、优化充能阶段、安排批次均衡。
- **材料提纯**：检测杂质、选择提纯工艺、提高有效产出。
- **供能调配**：匹配负载、构建组合模块、承接街区微电网订单。

行情技能支持低价进料与高需求出售，仓储设施限制危险或大体积批次，交易许可约束受管制能源。修复师能更换损坏控制板，但不会凭维修动作自动增加电芯剩余容量；能源技师能处理化学或储能状态，但不替代神经接口维修资质。

接入时保留实例现有 `capacity`、`purity` 字段，新增可审计的充能与提纯动作，按配方记录输入消耗。专业加成只改变工序成本或上限，不允许直接改钱包或复用展示动画决定产量。

## 生态培育者

核心循环为采购活性种源、检查保存情况、选择培养条件、消耗营养与工位、推进营业日、收获并销售。利润来自稳定批次和适配用途；变质、过度扩产和库存积压构成取舍。现实时间离线等待不会产生收益。

速生菌种包、营养培养液和生物凝胶对应不同培养路线。后续设备包括恒温培养箱、无菌操作柜和水循环架。阿苗需要稳定食材，宋宜关注有明确来源和许可的医用材料，屋顶种植社需要适应环境的种源。

三条分支：

- **保存护理**：延缓衰减、识别污染、维护种源活性。
- **性状筛选**：比较批次、稳定目标性状、保留种源谱系。
- **生产组织**：排布培养位、控制分批收获、履行持续供货合同。

通用保鲜技能作用于仓储，培育能力作用于培养中的工单。现有冷藏柜只能延长食品保存，不会将过期物品恢复为新鲜。修复师负责培养箱的机械维修，培育者负责其中的生物过程。

接入时新增培养工单、批次谱系和营业日推进规则。收获结果由开始时保存的种源与规则决定，刷新页面不重抽结果；生产上限受设施和工时约束。数据迁移为旧存档增加空工单列表，不修改原有食品日期。

## 数据经纪人

核心循环为确认所有权与授权、检测介质、制定恢复或解密方案、消耗算力与工时、校验可读内容、按约交付。收益来自可验证的内容恢复和信息整理服务。客户数据只进入对应工单，不能混入普通销售库存。

数据芯片、加密档案盒、电影卡和影像晶片是主要载体。后续设备包括只读恢复座、隔离计算机和校验阵列。温竹寻找完整档案，陆澈需要可靠导航记录，企业档案客户可能要求保密交付。

三条分支：

- **介质恢复**：坏块映射、冗余恢复、完整性校验。
- **授权解密**：验证凭据、识别封装、恢复受托访问。
- **信息编排**：去重与索引、交叉核对、交付可检索资料包。

通用交易规则决定介质的所有权与价格，职业能力处理其中内容。物理故障与数据完整度分别结算；接点清洁不会自动补回缺失扇区。首版不提供在线 AI 对话或运行时联网解密。

接入时在实例知识或独立数据附件中增加授权范围、校验和及恢复记录。新增 `recoverData`、`verifyData`、`deliverData` 动作，客户托管与收益结算沿用维修工单的隔离原则。前端只展示玩家已经获得的内容状态。

## 遗物策展人

核心循环为发现旧物、收集出处、比对证据、组织主题、寻找观众或买家、完成展览或拍卖。利润来自可信考据与主题组合，也可通过定向委托取得展览收入。藏品吸引力不会自动转化成无限每日客流。

古董六类商品以及有纪念意义的数据、工业、生活物件都可进入研究。后续设备包括档案阅览台、保护陈列箱和光学比对灯。白衡提供流转线索，罗槿关注生活史组合，温竹提供档案关联。

三条分支：

- **出处考据**：整理线索、交叉核验、形成证据分级。
- **主题展览**：组合叙事、布置展位、策划公共或私人展览。
- **藏家委托**：识别需求、谈判借展、组织有底价和费用的拍卖。

通用收藏树提供入门编目和展示收益，策展职业提供深度研究及专门订单。修复师负责技术修复，不因换了齿轮就证明年代与真伪；策展人可以辨识价值，但不获得无证维修的资格。

接入时扩展证据记录、展览合同与竞价规则，继续引用唯一的 `ItemInstance.id`。出借、展示、仓储、维修必须互斥；拍卖费与成交款在同一动作内结算，失去技能时不得删除藏品或重复领取历史奖励。

## 共用成长与最终里程碑

新职业开放后，通过取得资质和分配共享技能点接入，不重置现金、收藏或已有职业。主线点数不足以覆盖全部能力；无尽模式持续获得经验，长期允许跨职业成长。

每个职业通过 `masterySkills` 和 `finalMilestone` 声明胜利资格。首版修复师使用联络中枢的机电、供能和神经接口三阶段工单。未来职业的最终订单同样必须经过实际工序、成本与交付，不通过界面按钮直接写入胜利标记。
