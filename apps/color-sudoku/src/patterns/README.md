## 如何复核

- 种子寻址的是有限的部件配方，不代表每个 32 位整数都是新图。穷举 12 个主题共 720 个配方，按平移、旋转和双向镜像归一，各主题合计 657 种轮廓；有 63 个重复配方（8.75%）。同一形状换大棋盘补白或整倍放大，也仍算同形。正式 24 张之间的同形数为 **0**。
- 不能把平移一格当作备选巨变。允许最佳平移和八种方向后，主备仍要实际增删的格数依次为 `5, 7, 6, 6 / 7, 11, 6, 7 / 15, 14, 13, 10`。
- [图案测试](../../tests/patterns.test.ts)检验上述去重口径、四连通、关键负形、线索、色块和种子重现。可从仓库根目录运行 `node --test --test-isolation=none apps/color-sudoku/tests/patterns.test.ts`。形状审图不代替[独立证明与无伤回放](../solver/index.ts)。当种子或形状有变动，应同时更新打样并重新过出版门禁。
