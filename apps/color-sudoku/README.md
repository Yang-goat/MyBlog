# 涂色数独 · 奶团的贴纸册

Vue 3 + TypeScript 的独立数织游戏。首次进入从五格练习开始，之后有 5×5、7×7、10×10、12×12、15×15、20×20 六个尺寸，每档六关。当前尺寸六关各首次通关后升一级，解锁下一档。进度条显示当前尺寸已完成的关卡数。

看行列里的连续段数，选「涂色」或「标空」。鼠标按住拖动可连续标记，拖动遇到一次错误后，松手即可继续。棋盘上可用方向键移动，回车或空格落笔，`F` / `X` 或 `1` / `2` 切工具。大棋盘支持放大与行列定位。

首通每关得 100 金币。工坊商店出售留白贴（25 金币）、彩墨滴（55 金币）和软心糖（80 金币）。购买后在道具袋里用，分别随机标空一个未知空格、随机涂对一个未知色格，或恢复一次机会。全程无错且未用道具可得无伤爪印。

## 本地游玩

在仓库根运行 `pnpm.cmd color:dev`，打开 <http://127.0.0.1:4177/color-sudoku/>。要同时测试博客、作品集与返回导航，请构建完整站点并从同一回环地址提供整个 `src/.vuepress/dist/`，而不是双击 HTML。命令见[站点维护](../../docs/maintenance.md)。不需要注册、后端服务或原作素材。

若完整站点已经构建，只需从仓库根目录执行下列命令，再打开 <http://127.0.0.1:4178/color-sudoku/>。按 `Ctrl+C` 关闭本地预览。

```powershell
python -m http.server 4178 --bind 127.0.0.1 --directory src/.vuepress/dist
```

## 一页题如何进入册子

1. [图案生成器](src/patterns/index.ts)按种子组合贴纸轮廓。颜色与 0/1 掩码共用同一张方格纸。[黑白打样](src/patterns/README.md)列出六册的主备轮廓。工坊横幅由 ImageGen 生成，作为本地 WebP 资源随站点构建。
2. [出版门禁](scripts/edition.ts)先认证本关同档的备用种子，再检验候选。验证失败、超时或与已收录轮廓等价时改用已认证备用；没有合格备用则拒绝构建。浏览器领取的是固定版本，不根据刷新时间重新抽题。
3. [唯一性计数](src/solver/uniqueness.ts)与[无猜路线搜索](src/solver/deductions.ts)独立，只用行列线索。后者把一行或一列的全部强制格与自动封格视为一步，合并相同下一棋盘，对完整路线计数到二即足以判为多路线。
4. [证明重放](src/solver/index.ts)逐步复核依据，调用[正式回合规则](src/core/game.ts)完成三机会对局。构建会核验[归档证书](evidence/edition-proofs.json)，不向前端提供示范路线或出题工具。

## 收藏和恢复

[本机存档](src/core/save.ts)保留每关的种子、落笔和道具使用记录，以及商店交易。旧版兼容读取已有的贴纸、无伤爪印和进行中的棋盘。金币余额由已首通的关卡收入减去购买支出，库存由购买量减去已使用量。不同来源（含端口）的浏览器存档相互独立。
